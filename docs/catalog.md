## Layouts

| Layout | Description |
|---|---|
| `hero` | One device centered and turned slightly (angle, default 18°). With several devices, falls back to 'arc'. |
| `row` | Side by side, facing forward, evenly spaced (spacing = gap as a fraction of device width, default 0.25). |
| `arc` | Side by side on a gentle curve: outer devices pushed back and turned toward the center (angle default 16°). |
| `fan` | Overlapping like a hand of cards, tilted around a pivot below them (angle default 12°). |
| `stack` | Staggered diagonally in depth, all turned the same way (angle default 25°); the last device is in front. |
| `grid` | Flat grid facing the camera (columns default √n). |
| `circle` | On a ring facing outward, for turntable/carousel motion (rotate the ring with apply_motion on the group). |
| `showcase` | Largest device in the center, smaller ones in front at its sides (e.g. laptop + phone, tablet + phones). |

## Motions

| Motion | Kind | Description |
|---|---|---|
| `turntable` | device | Full spin around the vertical axis (amount = degrees, default 360), constant speed. |
| `slow-turn` | device | Gentle turn from -amount to +amount degrees around Y (default 15). |
| `float` | device | Soft hovering up and down (amount = meters, default ~3% of device height). |
| `rise` | device | Rises into place from below while fading in (entrance). |
| `drop-in` | device | Drops into place from above with a small overshoot (entrance). |
| `enter-left` | device | Slides in from the left while turning to face the camera (entrance). |
| `enter-right` | device | Slides in from the right while turning to face the camera (entrance). |
| `exit-left` | device | Slides out to the left (exit, at the end of the timeline). |
| `exit-right` | device | Slides out to the right (exit, at the end of the timeline). |
| `fade-in` | device | Opacity 0 → 1. |
| `fade-out` | device | Opacity 1 → 0 at the end. |
| `spin-reveal` | device | Starts showing its back, spins to face the camera (entrance). |
| `tilt-up` | device | Starts lying back, tilts up to face the camera (entrance). |
| `lid-open` | device | Laptops: opens the lid from closed to its resting angle. |
| `lid-close` | device | Laptops: closes the lid (at the end). |
| `screen-on` | device | Screen brightness 0 → 1, like the display waking up. |
| `push-in` | camera | Camera dollies toward its target (amount = fraction of distance, default 0.2). |
| `pull-out` | camera | Camera dollies away from its target (amount default 0.2). |
| `orbit` | camera | Camera arcs around its target (amount = total degrees, default 30), eased. |
| `pan-left` | camera | Camera and target slide left (amount = fraction of distance, default 0.12). |
| `pan-right` | camera | Camera and target slide right (amount default 0.12). |
| `crane-up` | camera | Camera rises while keeping its target (amount = fraction of distance, default 0.25). |
| `zoom-in` | camera | Narrows the field of view (amount = fraction, default 0.2). |
